# Temporal analyses

This directory contains descriptive time plots for the existing preliminary
RGB/HSV measurements. No new image pixels are measured by the all-recipe
timeline script.

## All recipes

- [Consolidated comparison of Recipes 5–14](consolidated/README.md)
- [Coverage by recipe](consolidated/recipe_coverage_comparison.csv)
- [Availability and source CSVs](consolidated/input_availability.csv)
- [Per-vial temporal statistics](consolidated/temporal_summary_recipes_5_14.csv)
- [Reusable timeline script](analyze_recipe_timelines.py)

Run the all-recipe timeline script from the repository root:

```bash
python results/temporal_analysis/analyze_recipe_timelines.py
```

It reads the shared video 5 labels and existing measurement, exclusion, and
missing-frame CSVs. It writes recipe-specific timeline CSVs, per-vial summaries,
RGB/HSV plots, and frame coverage plots for Recipes 5–7 and 9–14, plus the
consolidated comparison. Recipe 8 is read from its existing updated temporal
CSV and is not regenerated by this script. The recipe pages are:

- [Recipe 5](recipe_5/README.md) · [Recipe 6](recipe_6/README.md) · [Recipe 7](recipe_7/README.md)
- [Recipe 9](recipe_9/README.md) · [Recipe 10](recipe_10/README.md) · [Recipe 11](recipe_11/README.md)
- [Recipe 12](recipe_12/README.md) · [Recipe 13](recipe_13/README.md) · [Recipe 14](recipe_14/README.md)

The shared labels path in this checkout is
`data/raw/recipe7/labels_video5_frame_labels.csv`. Although its parent folder is
named `recipe7`, the CSV has labels for Recipes 5–14. The temporal script needs
that file and the tracked measurement CSVs; it does not need the raw images.

Each elapsed time starts at the first frame labeled `in_fill=1` for that vial.
This is a label-based timeline origin, not a verified dispense-start time.
Unmeasured frames are retained with blank color values and a status; no values
are inferred for excluded or missing images.

## Recipe 8 analysis history

Recipe 8 has a sequence of related analyses. The following files are retained
for traceability; they use different time anchors or measurement coverage:

1. [Initial relative-time analysis](recipe_8_temporal_measurements.csv) uses 24
   original fixed-ROI measurements. Its clock begins at each vial's first
   retained measurement. The corresponding script is
   [analyze_recipe_8_temporal.py](analyze_recipe_8_temporal.py), and its original
   notes and plots are in the files at this directory level.
2. [Labeled fill timeline](recipe_8_fill_timeline/README.md) places those
   measurements among all 55 labeled in-fill frames for the three vials.
3. [Original-image review](recipe_8_original_image_review/README.md) documents
   a review of the 31 previously excluded frames. One cautious relocated-ROI
   measurement was added, giving 25 measured values and leaving 30 frames
   excluded. Its outputs remain in that subfolder.

These are preliminary, descriptive results. Recipe 8's extra sample uses a
different ROI position and should not be treated as directly equivalent to the
fixed-ROI points. None of the analyses establishes contamination or a cause for
the observed color changes.

For the original-image review script, the Recipe 8 ZIP archive must be supplied
with `--zip`; the archive itself is not tracked. Raw images in `data/raw/` are
also excluded from Git. See the [main README](../../README.md) for dataset and
environment setup.
