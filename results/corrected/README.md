# Corrected Dataset 2 color analysis

This folder is a **separate rebuild** of Phase 1 and Phase 2. The previous
`results/recipe_*/`, `results/temporal_analysis/`, and
`results/anomaly_detection/` remain unchanged for comparison. The original
still-image labels used photo-clock seconds against video-clock vial windows.
The corrected outputs here use the corrected still labels for an audit and
video-clock measurements for all new color calculations.

## What changed

- [Label audit](label_audit.csv): all 845 stills, original versus corrected
  vial/recipe/fill assignments, direct video-match timing, and a boundary flag.
  The original 509 `in_fill` stills include only 26 with the same vial after
  correction; 288 map to another vial and 195 fall between fills. The
  corrected labels mark 516 stills as `in_fill`.
- [Legacy still measurements](legacy_stills_relabelled.csv): the 271 saved
  Phase 1 pixel values joined to corrected metadata by exact filename.
  Seventeen fall outside the corrected fill, 17 need boundary review, and 237
  are candidates for a fresh ROI check. These pixel values **do not** train the
  new references, because they use the older fixed ROI and were selected under
  the old labels.
- [Corrected Phase 1](phase1/recipe_summary.csv): 1,067 unique labeled video
  fill frames across Vials 1–30, after discarding three duplicated source
  filenames. Salah's moving liquid ROI returns 879 high-confidence RGB/HSV
  measurements; the other 188 frames stay visible in the timelines with blank
  analysis color values. The [per-vial summary](phase1/vial_summary.csv) and
  `phase1/recipe_N/` folders contain coverage, RGB/HSV summaries, full
  video-time timelines, and color-over-progress plots for each recipe.
- [Corrected Phase 2](phase2/README.md): provisional stage references and an
  evaluation on the other two vials of each recipe. It accepts the same six
  color fields and confidence signal produced by Salah's liquid finder.

The still-label audit marks a row for review when its fitted time is within
one second of any fill-window boundary, its match was a clock-fit outlier, or
its direct video-frame match and fitted time point to different vials. The
three conditions overlap: 58 rows are within one second, 30 are fit outliers,
and seven have different direct/fitted vial assignments; **86 unique rows**
need review. This is conservative. The main video-based summaries bypass the
photo-clock conversion altogether.

## Method and reproducibility

The input CSV snapshots and their provenance are in
[inputs/color_check](../../inputs/color_check/README.md). `frame_colors.csv`
was generated by Salah's `liquid_finder` on Video 5. Each new timeline uses
video time, the vial fill windows, and `fill_progress` from the saved video
frame label. RGB and OpenCV HSV values are included in summaries, graphs, and
reference fitting **only when** a vial and liquid were found and confidence is
`high`. A low-confidence value remains in the source snapshot but is blank in
the analysis timeline. Progress runs from 0 to 1 within the labeled fill
window; it is not a measured liquid volume.
The source branch's [ROI review sheet](../../inputs/color_check/examples/video5_liquid_roi_review_sheet.jpg)
shows representative measurement boxes for all 30 vials.

From the repository root, with `requirements.txt` installed:

```bash
PYTHONPATH=src python -m vialsense.corrected_cli build
PYTHONPATH=src python -m unittest discover -s tests -v
```

`build` rewrites only `results/corrected/`. Use `--output-dir` to build in a
temporary location. Its CSV/JSON outputs are deterministic from the checked-in
snapshots; the [input hashes](input_hashes.json) identify the exact source
files. Repeating the *pixel extraction* requires the original Video 5 MP4
and Salah's extraction and liquid-finder code from `color-check`. The MP4 is
not included in Git, so this rebuild verifies the saved numerical output and
labels but cannot independently repeat every image measurement.

## Limits

The clock correction is strongly supported by frame-match scores and the
vial-window table, but boundary stills remain withheld from reuse. Salah's
finder was tuned for this camera view; high confidence is an algorithmic
quality indication, not a verified ground-truth liquid mask. No vial here is
confirmed good or contaminated. The new references and scores remain
provisional, and their review flags cannot establish a contamination rate.
